# Adult Income Classification

Проект посвящён задаче бинарной классификации дохода на основе датасета **Adult (Census Income)**. В ходе работы были выполнены анализ данных, предобработка признаков, построение моделей машинного обучения и сравнение их качества.

---

## Описание проекта

В качестве исходных данных использовался набор `adult.csv`, содержащий демографические и социально-экономические признаки. Целевая переменная — `income`, которая показывает, превышает ли доход значение `50K`.

Основная цель проекта — построить модель, способную предсказывать уровень дохода по набору признаков, а также сравнить эффективность нескольких алгоритмов классификации.

## Данные

Датасет содержит следующие признаки:

* `age`
* `workclass`
* `fnlwgt`
* `education`
* `educational-num`
* `marital-status`
* `occupation`
* `relationship`
* `race`
* `gender`
* `capital-gain`
* `capital-loss`
* `hours-per-week`
* `native-country`

Целевая переменная:

* `income` — принимает значения `<=50K` и `>50K`.

---

## Что было сделано

В рамках проекта были выполнены следующие этапы:

* загружен и изучен исходный датасет;
* проверены размерность данных, типы столбцов и описательная статистика;
* построены гистограммы распределений признаков;
* проведён анализ целевой переменной и обнаружен дисбаланс классов;
* удалён дублирующий признак `education`;
* значения `?` в категориальных столбцах заменены на наиболее частотные значения;
* выделены числовые и категориальные признаки;
* числовые признаки масштабированы с помощью `StandardScaler`;
* категориальные признаки закодированы с помощью `OneHotEncoder`;
* обучены и сравнены несколько моделей классификации;
* подобраны гиперпараметры с помощью `GridSearchCV` и `StratifiedKFold`.

---

## Используемые методы

### StandardScaler

Использовался для масштабирования числовых признаков, чтобы привести их к единому масштабу.

### OneHotEncoder

Применялся для преобразования категориальных признаков в числовой формат, пригодный для обучения моделей.

### GridSearchCV

Использовался для подбора гиперпараметров моделей и поиска оптимальных настроек.

### StratifiedKFold

Применялся для кросс-валидации с сохранением пропорций классов в каждом фолде.

### Метрики качества

Для оценки моделей использовались:

* **Accuracy** — доля правильных предсказаний;
* **F1-score** — более информативная метрика при дисбалансе классов.

## Модели, которые были обучены

В проекте были протестированы следующие модели:

* `LogisticRegression`
* `DecisionTreeClassifier`
* `RandomForestClassifier`
* `XGBClassifier`

Для каждой модели был выполнен подбор параметров, а затем проведена оценка на тестовой выборке.

---

## Результаты

| Модель             | Accuracy | F1-score |
| ------------------ | -------- | -------- |
| LogisticRegression | 0.8527   | 0.7826   |
| DecisionTree       | 0.8207   | 0.7412   |
| RandomForest       | 0.8291   | 0.7551   |
| XGBoost            | 0.8196   | 0.7385   |

## Выводы

По результатам экспериментов лучшей моделью оказалась `LogisticRegression`, которая показала наибольшие значения accuracy и F1-score. Это говорит о том, что после корректной предобработки данных линейная модель хорошо справляется с задачей классификации дохода.

Модели на основе деревьев также показали достойные результаты, но в данной задаче не смогли превзойти логистическую регрессию.

Таким образом, проект демонстрирует полный цикл решения задачи классификации: от анализа и подготовки данных до обучения и сравнения нескольких моделей машинного обучения.
